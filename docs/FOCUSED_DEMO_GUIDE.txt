HOW TO USE FOCUSED DEMO
=======================

1. LOAD DEMO DATA
   poetry run python -m scripts.seed_focused_demo_dataset
   (This clears existing URLs and seeds only demo dataset)

2. RUN BENCHMARK
   poetry run python -m scripts.eval_demo_accuracy
   Shows how scanner performs on focused dataset

3. QUERY VIA UI
   - Open localhost:3000
   - Threat Database page loads with 50 URLs
   - Search by domain: "incometax.gov.in"
   - Filter by campaign: "campaign_001"
   - View threat breakdown chart

4. QUERY VIA API
   GET /api/v1/urls?skip=0&limit=50
   Returns all 50 demo URLs

5. SCAN NEW URL
   POST /api/v1/scan
   {"url": "https://any-url.com"}
   Shows how real-time scanning works
