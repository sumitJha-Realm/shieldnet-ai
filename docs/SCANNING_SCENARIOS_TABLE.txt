Scenario 4: Coordinated Phishing Campaign
Problem: Multiple phishing domains targeting PayPal users
Demo: Show paypal-verify-account.tk and paypal-update-billing.xyz (same campaign)
Message: Scanner identifies organized attacks and blocks all related URLs

Scenario 5: Domain Canonicalization
Problem: www.google.com should be treated same as google.com
Demo: Show both google.com and www.google.com have same status and risk
Message: Scanner normalizes domain variants for consistent protection

Scenario 6: DGA Domain Detection
Problem: Malware using domain generation algorithm to create random domains
Demo: Show xkfrzmkbpq.tk blocked (Risk 81)
Message: Scanner detects algorithmic patterns and entropy anomalies
